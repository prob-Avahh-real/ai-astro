# ai-astro（星盘 · Astro Chart）

交互式单页星盘可视化与占星排盘工具（已归档于 `archive/ai-ml/ai-astro`）。

## 功能概览

- 基于 HTML5 / CSS Grid / SVG 的出生星盘绘制与相位（和谐 / 挑战）可视化
- 响应式双栏卡片布局（输入出生时间地点参数 + 星盘与星体落座解读）
- 附带 Node.js 冒烟校验测试（`test/`）

## 目标平台（Target 判定）

- **移动端**：可选（响应式 Web，已搁置独立壳）
- **智能硬件**：可选（可搁置）

## 快速运行与验证

```bash
# 本地静态预览
npx --yes serve .

# 运行自动化冒烟测试
npm test
```
